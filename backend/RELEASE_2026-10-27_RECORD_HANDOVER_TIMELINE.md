# 老人记录即时分析、交班与时间线发布记录

## 已实现

- Schema 9 新增 `record_analyses`。Schema 8→9 先备份原 store，再仅将记录分析作业中的 queued/processing 状态标记为 `failed/requires_inline_reanalysis`；已完成作业和其他集合保留。
- 老人工作页正式记录先保存，再锁外同步分析。分析失败保留记录并支持按原记录 ID 重试；结果按记录修订保存，人工确认使用幂等键，任务及明确重复频率提示只在确认后创建。
- 新记录分析不进入旧 `care_jobs`。后台保留计划排期；旧记录分析 worker 不再启动。
- 交班分析接收可编辑文本并返回原文依据和待核对任务建议；已有任务按原 source ID 延续，新任务须人工确认并补齐老人、目标班次、负责人、截止和完成标准。
- 护理员交班响应按当前老人范围裁剪。家属交班读取仅返回其当前授权下已发布且来源仍有效的公开简报，不返回内部交班明细。
- 时间线筛选、计数、分页和稳定排序以服务端审计登记时间为准，实际发生时间独立返回。
