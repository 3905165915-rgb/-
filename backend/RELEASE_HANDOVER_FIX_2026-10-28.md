# 交班分析与提交阻断修复

## 问题与修复

1. 护理员交班页面误用管理人员专用 `/staff/directory`，403 会使并行读取整体失败。配套前端改为现有 `/staff` 简要查询；管理目录仍仅限管理人员，不放宽后端权限。
2. 班次列表按时间倒序返回，旧页面直接取首项，可能将最远未来班次作为交出班次，并选择更早的接班班次。配套前端现在验证本人可交出的开放班次，优先当前班和按时间排序的下一班；修复不合法的旧草稿班次组合并保留文字。
3. 没有正式班次条目时，护理员自己输入的交班文字即使成功分析，摘要也会被读取过滤。后端现允许摘要生成者核对自己的纯文字摘要。其他护理员仍不读取此无老人来源的自由文本；存在无权访问的来源条目时，原有过滤规则不变。
4. 前端补充人工核对路径，使用已有提交协议 `approve_ai_summary=false`，不要求模型成功。不完整的新任务不创建，也不伪装为智能分析结果。
5. 每次进入分析/人工核对前刷新服务器交班来源；提交继续校验版本和来源。原任务保持原编号，下一班接收后再接续。
