# 统计与案例导出

仅主管/管理员可访问，均在`/api/v1`；所有API响应Cache-Control:no-store。单机构当前JSON快照，未接前端。

GET `/reports/metrics?start=YYYY-MM-DD&end=YYYY-MM-DD`：中国时区，start含、end不含，1–366天。as_of由服务端记录本次计算时间。区间选取业务批次，结果状态来自当前存储，不是任意历史时点回放。

| 指标 | 分母/选取方式 | 分子 |
|---|---|---|
| 已生成计划服务完成率 | scheduled_at在区间且已到服务时刻的唯一occurrence_key；取消保留，补发链仅末项 | 末项completed |
| 上述服务按时完成率 | 同上 | completed_at≤due_at |
| 接班接收率 | submitted_at在区间的已提交交班全部条目，不含草稿 | 当前received条目；澄清中不算已接收 |
| 事件/整改 | occurred_at在区间 | 上报数、当前关闭数、未关闭且due_at<as_of的整改数 |
| 家属反馈 | created_at在区间 | 创建数、主管已回复关闭数，不等于满意率 |

空分母ratio=null，不显示100%；手工任务另计，不混入计划服务。无效计划时刻计数警示；同一次服务存在多个末端的异常补发链返回409，不猜测或重复计数。未来服务排除。不计尚未生成的应执行计划，所以**不能把这个完成率称作全机构计划履约率**；完整履约统计仍需计划生效历史和应生成服务台账。

POST `/reports/elders/{elder_id}/export`：JSON `{reason:"导出用途", include_text:false}`；附件JSON，生成随机文件名，记录导出人/用途/模式/时间。默认只含单老人记录、任务、记忆及采用关系、评估、计划、变更核验、交班条目、事件和整改的必要状态与时间元数据，对象ID替换为本次随机映射，不含姓名、联系方式、员工信息和正文。交班只取该老人条目，不导出可能包含其他老人的整班摘要。默认去标识仍可能再识别，不可直接公开真实个案。

明确include_text=true才附内部正文/证据/修订信息；即使如此也不打包账号、家属授权凭证或联系方式。正文可能含当事人主动写入的身份信息，只能授权内部使用；不是家属可下载材料，也不是经过专业脱敏审查的公开案例。案例生成与导出审计同事务，失败不返回成功附件。未提供CSV/PDF排版或自动报送监管系统。
