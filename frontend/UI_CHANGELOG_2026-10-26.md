# 2026-10-26 界面与身份入口改进

## 参考与范围
参考用户 DOCX 中的浅紫白色角色选择卡、老人工作卡、管理看板和手机页面。保留既有业务接口与页面能力，本轮集中调整入口与视觉。

## 界面
- 首页以长者户外照片作背景，浅色玻璃身份卡，悬停轻微上浮；账号密码入口折叠保留。
- 提供护理员、护士／主管、管理员、家属四个演示入口，无需输入密码。护士复用现有主管角色，不新增临床权限。
- 管理工作区统一浅紫背景、圆角面板、侧栏与看板层次；手机卡片与桌面风格一致。
- 顶栏新增切换身份入口，清除当前会话后返回角色选择。
- 尊重降低透明度设置及减少动态效果偏好。管理表格保持清晰底色。
- 手机管理员进入可响应的管理网站；手机护士及护理员进入移动工作台，家属保留授权动态。

## 接口约定
POST /api/v1/auth/demo-login，请求 role 为 caregiver / supervisor / admin / family。
后端仅对演示环境及显式启用的有效演示账号签发正常登录凭证。各业务权限继续由服务端核验。
