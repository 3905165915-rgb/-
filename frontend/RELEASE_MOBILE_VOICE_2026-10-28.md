# 手机录音与文件选择修复（待发布）

## 问题及证据

- 老人快速记录页未暴露响应式录音状态；录音开始后按钮仍为“录音”，容易重复点击。多个入口分别维护 MediaRecorder，缺少授权等待锁、停止处理锁和浏览器中断处理。
- 服务器只读日志核对：截图对应时段存在连续成功的语音请求，随后返回 429；同一时段 Nginx 错误日志明确记录请求限流。此前页面直接 `response.json()`，HTML 限流页触发英文 JSON 解析异常。
- 这些证据不等于已复现用户手机的浏览器自行终止录音。移动浏览器、麦克风权限、系统打断仍须实机复测。

## 修改范围

- 记录、通用工作流与交班共用录音状态控制器；开始、授权等待、录音计时、停止处理、转写分别展示。只有主动停止或达到 60 秒才识别；浏览器自行停止提示重录。
- 拦截授权等待期间重复点击、处理期间再次开始、过短录音、空录音及接近静音的录音。录音/转写期间阻止保存和交班，转写不自动保存业务记录。
- 选择浏览器支持的录音 MIME 类型；取消、切换老人/班次、离开组件时关闭音轨并取消请求，过期结果不得填入新上下文。音频解码完成后再次核验取消状态。
- HTML/非法 JSON、401/403/413/429/504 及厂商失败映射为预定义中文提示；失败保留原文字，无自动收费重试。有效转写仍需人工核对；静音检查不能保证消除识别错误。
- 保留此前未发布的任务附件、照片、语音文件控件布局修改：自定义按钮替代原生“未选择文件”，长文件名省略；记录操作在窄屏下纵向排列。
- 不改变后端 API、模型、密钥、权限或 Nginx 限流配置。

## 验证

- 全量单元测试：69 个文件、788 项通过，含新增录音、音频预检与异常响应 22 项。
- 前后端两个前端应用的 TypeScript 检查、生产构建通过；本次改动 ESLint 无错误，仓库既有模板格式警告未整体重写。
- 交班专项浏览器回归：4 项通过。
- 桌面 Edge 真实 MediaRecorder + 合成音源，在 320/375/390 像素视口核对计时、停止后才请求、过短音频不请求、HTML 429 中文反馈及保留文字、长文件名不撑开页面，均通过，无页面运行异常。
- 修复后的本地前端录制合成音源，停止后经公网真实语音接口调用硅基流动 `Qwen/Qwen3-ASR-1.7B` 一次，成功回填并保留“没有外出”；回执 `saved=false`、`requires_confirmation=true`。没有提交护理记录或交班。单样例不代表真实护理语音准确率。
- 浏览器测试的三种宽度属于窄屏模拟，不代表 Android/iOS 真机验收。测试未点击保存记录或提交交班。
- 本机截图和结构化证据保存在被 Git 忽略的 `test-results/voice-fix-20261028/`。

## 发布状态与人工复测

本次代码尚未推送、尚未部署，线上页面不会因本地修改自动更新。服务器仅做只读日志检查。

发布后在用户实际手机浏览器中允许麦克风，点击“开始录音”，确认秒数增长，持续说话数秒后点击“停止录音”；核对文字保留原有输入。快速开始/停止应提示过短且不产生识别请求；被系统中断则提示重录。频繁操作触发限流时应显示中文提示，不能出现英文 JSON 异常，也不应改动原文字。
